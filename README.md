# ☁️ Cinnabudget v2

A cozy and minimalist expense tracker designed for personal budgeting.

Cinnabudget was created to help me manage my daily expenses based on my pay cycle. Instead of using feature-heavy finance apps, I wanted something simple, lightweight, and focused only on the features I actually use.

This project is built for personal use but is designed with the possibility of adding more features in the future for friends and loved ones.

---

## ✨ Features

- 💰 Set a budget for each pay cycle
- 📝 Record daily expenses
- 📅 Automatic pay cycle tracking
- 📊 Budget summary
  - Total Budget
  - Total Spent
  - Remaining Budget
- 📈 Budget usage progress bar
- 🌸 Friendly budget status messages
- 📄 Export expenses to Excel (.xlsx)
- 💾 Local Storage (data stays in your browser)
- 🎨 Cute and cozy Cinnamoroll-inspired interface

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
- Local Storage API
- SheetJS (Excel Export)

---

## 🎯 Purpose

The goal of this project is to create a clean and easy-to-use expense tracker that focuses on budgeting by pay cycle.

Many finance apps include features that I don't personally need. Cinnabudget keeps things simple while providing the essentials for tracking spending and monitoring a budget.

This project also serves as a way to practice front-end development, JavaScript, and user interface design.
